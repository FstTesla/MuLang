# Standard-library constants

Constants are immutable provider globals in the Math.Constants module. All use
deterministic .NET values and require MuLang 1 or later.

Floating-point constants use the platform's IEEE 754 binary64 representations
for `Math.E`, `Math.PI`, and `Math.Tau`.

## e

**Stable identifier:** `mulang.std.math.constants.global.e`

**Since:** 0.2.0

**Type:** `float`

**Value:** Euler's number

## maxInt

**Stable identifier:** `mulang.std.math.constants.global.maxInt`
